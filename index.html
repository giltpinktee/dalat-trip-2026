Đồng bộ tức thì 4 máy

Không cần server — dán 1 link Firebase Realtime Database miễn phí của Google để 4 máy nhảy vote tức thì.

Tạo link miễn phí trong 2 phút:
1. Vào console.firebase.google.com → Create project.
2. Chọn Build → Realtime Database → Create Database (Singapore, Test mode).
3. Copy link https://...firebasedatabase.app dán vào ô trên.
4. Bấm Copy link gửi Messenger gửi cho 3 bạn kia — bấm vào là tự đồng bộ!
